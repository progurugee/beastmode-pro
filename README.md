# BEASTMODE PRO

A simple Streamlit website prototype for the Deriv analyzer dashboard.

## Deploy
1. Create a new GitHub repository named `beastmode-pro`.
2. Upload `app.py`, `requirements.txt`, and optionally this README.
3. On Streamlit Community Cloud, create an app from that repository.
4. Set the main file path to `app.py` and deploy.

## Important
This prototype uses clearly labelled sample digits only. It does not connect to Deriv and does not place trades. Live market-data integration and any trading features must be added and tested separately. Never commit API tokens or passwords to GitHub.
